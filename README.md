# Anatolii Moroz — online CV

Static multilingual CV (Spanish, English, Ukrainian and Russian).

## Publish free with GitHub Pages
1. Sign in to the GitHub account that owns `anmorozsp-ship-it.github.io`.
2. Create a **public** repository named `cv`.
3. Upload `index.html`, `robots.txt` and `sitemap.xml` to the repository root.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, then Save.
6. When GitHub publishes the site, open the Pages URL and enable **Enforce HTTPS**.

Expected address: https://anmorozsp-ship-it.github.io/cv/

The CV uses the browser print dialog for PDF export. Choose **Save as PDF**.

## Search visibility
After publication, add the exact URL as a property in Google Search Console, verify ownership, inspect the homepage URL and request indexing. Submit `sitemap.xml`. Indexing is not guaranteed and may take time.
